# 墨房 (서예 연습 앱 · 중국어판)

앱 화면과 AI 첨삭은 전부 중국어입니다. 빌드·설치 안내는 아래 한국어 그대로.

## 빌드 방법 (GitHub Actions)
1. GitHub에 새 저장소 생성 (예: seoye)
2. 이 폴더의 파일 전부를 저장소 main 브랜치에 업로드
3. Actions 탭에서 "Build APK" 실행 완료 대기 (수 분)
4. 실행 결과 하단 Artifacts에서 `seoye-apk` 다운로드 → 압축 안의 app-debug.apk 를 폰에 설치

## AI 첨삭 사용
앱 설치 후 [기록] 탭 하단 설정에서 Anthropic API 키(sk-ant-...)를 저장하면
[첨삭] 탭의 AI 첨삭이 작동합니다. (console.anthropic.com 에서 발급)
키가 없어도 체본 보기·겹쳐 비교·학습·기록은 전부 사용 가능합니다.
